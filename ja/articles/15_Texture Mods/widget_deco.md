# Deco フォルダ

Deco フォルダ内に置いた png 画像は、デコとしてウィジェット（ゲーム画面上の各ウィンドウやパネル）に貼り付けられます。

+ **場所：** 下記の[場所の節](#deco-folder-location)を参照
+ **ファイル形式：** png
+ **背景：** 透明を推奨
+ **サイズ：** 自由。最初は元の画像サイズで表示され、ゲーム内で拡大・縮小できます。
+ **ファイル名：** deconame.png
  + 英数字での命名を推奨します。ウィジェットはファイル名でデコを覚えているため、使用中の画像のファイル名は変更しないでください。

## 使い方

1. ウィジェットを右クリック → **スタイル** → **デコの編集**。スタイルメニューがないウィジェットもあります。
2. 空いている場所を左クリック → **デコを追加** → 画像を選択。自分の画像はゲーム標準のデコの後ろに並びます。
3. デコはドラッグで移動できます。デコを左クリックすると、色・サイズ・角度の変更や削除ができます。
4. 終わったら右クリック → **編集終了**。

ゲーム起動中にローカルの Deco フォルダへ追加した画像は、次に **デコを追加** を開いたときに表示されます。Mod の画像はゲームの再起動が必要です。

## 場所 {#deco-folder-location}

ローカルに保存することもできます：

+ **場所：** `%localappdata%low\Lafrontier\Elin\Custom\Deco`
+ **開き方：** ゲーム内で Esc → ツール → 差し替えフォルダを開 → Deco フォルダを探す

Mod として使用することもできます（Steam ワークショップでの配布など）：

+ **場所：** `<ElinGamePath>/Package/<ModName>/Deco`。[Mod パッケージ](../2_Getting%20Started/basic_mod)の必須ファイルも必要です。

Mod とローカルフォルダに同じファイル名の画像がある場合は、Mod の画像が使われます。

画像が見つからない場合（提供元の Mod の購読を解除したなど）、デコはゲーム標準の画像で表示されます。画像を戻してゲームを再起動すると元に戻ります。

::: tip
Deco フォルダはウィジェットのデコ専用です。[ソースシート](../10_Source%20Sheets/tile)で追加するマップの装飾のテクスチャは `Texture/Deco` に置きます。
:::
