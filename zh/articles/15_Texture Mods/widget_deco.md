# Deco文件夹

放在 Deco 文件夹里的 png 图片，可以作为装饰贴到控件（游戏画面上的各个窗口和面板）上。

+ **位置：** 见下文[位置章节](#deco-folder-location)
+ **文件类型：** png
+ **背景：** 建议透明
+ **尺寸：** 不限。图片一开始按原始大小显示，之后可以在游戏内缩放。
+ **文件命名：** deconame.png
  + 建议用英文和数字命名。图片用上之后不要再改文件名，控件是按文件名记住装饰的。

## 使用方法

1. 右键控件 → **样式** → **设置装饰**。不是每个控件都有“样式”菜单。
2. 左键点击空白处 → **添加装饰** → 选择图片。你的图片排在游戏自带装饰的后面。
3. 拖动装饰可以调整位置；左键点击装饰，可以修改颜色、大小、角度，也可以移除它。
4. 编辑完成后，右键 → **结束编辑**。

游戏运行期间放进本地 Deco 文件夹的新图片，下次打开**添加装饰**时就能看到；mod 里的图片要重启游戏后才会出现。

## 位置 {#deco-folder-location}

可在本地储存

+ **位置：** `%localappdata%low\Lafrontier\Elin\Custom\Deco`
+ **打开方式：** 游戏内按 Esc → 工具 → 打开自定义文件夹 → 找到Deco文件夹

也可以做成 mod 使用（例如发布到创意工坊）

+ **位置：** `<游戏安装目录>/Package/<ModName>/Deco` ，mod 还需要准备[模组包](../2_Getting%20Started/basic_mod)的必需文件。

如果 mod 和本地文件夹里有同名图片，游戏会使用 mod 里的那张。

如果图片找不到了（比如退订了提供它的 mod），装饰会暂时显示成游戏自带的一张图片。把图片放回去并重启游戏即可恢复。

::: tip
Deco 文件夹只用于控件装饰。通过[源表](../10_Source%20Sheets/tile)添加的地图装饰，贴图要放在 `Texture/Deco`。
:::
