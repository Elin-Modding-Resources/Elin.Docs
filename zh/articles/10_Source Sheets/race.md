# 种族表 (Race)

<LinkCard t="SourceChara/Race" u="https://docs.google.com/spreadsheets/d/1CJqsXFF2FLlpPz710oCpNFYF4W_5yoVn/edit?gid=1953808581#gid=1953808581" />

官方源表中的种族表（Race 表）位于 SourceChara 表内，可通过底部的标签页切换。

**制作源表时，必须完整复制官方源表的前三行，并将你的数据从第四行开始录入。**

::: details 关于列、空行和空格子
**缺少的列会被填成空值**，游戏会在日志（Player.log）里输出 `#source ill-format` 警告并继续加载；列顺序被打乱时会按表头名自动重新映射。尽管如此，还是建议把官方表头整行原样复制，从源头避免这两种情况。

**`id` 留空的那一行会中止整张表的读取**，它之后的所有行都不会载入，而且没有任何提示。除非你是有意为之，否则不要用空行给数据分组。

**空格子不等于空值**：游戏会改用第 3 行的默认值。本表的默认值有：`vigor`=100、`DV`/`PV`=0、`geneCap`=3、`material`=`meat`、`corpse`=`_meat,20`、`blood`=2、`age`=`8,50`、`food`=100。

你也可以改第 3 行的默认值，让它作用到其余所有行。
:::

## 列说明

|列名|类型|描述|
|-|-|-|
|id|string|每条数据的唯一标识，用来与表中其他数据区分。如果你的 ID 与官方条目或其他 Mod 的 ID 重复，最后加载的表会覆盖之前的所有条目。不能包含空格或特殊字符。|
|name_JP|string|种族的日文显示名称。|
|name|string|种族的英文显示名称。其他语言使用 SourceLocalization.json。|
|playable|integer|创建角色时玩家能否选择这个种族。`1`：默认可选。`2`–`6`：需要开启「扩展种族」选项。`7`–`8`：需要开启「全部种族」选项。`9`：任何情况下都不可选，通常留给神/恶魔等特殊种族。|
|tag|string[]|种族的标签列表，逗号分隔。参见下方[标签参考](#标签参考)。|
|life|integer|生命力，计算血量（HP）的基础值。|
|mana|integer|玛娜，计算法力（MP）的基础值。|
|vigor|integer|活力，计算黄条（SP）的基础值。|
|DV|integer|基础闪避值，即种族天生的闪避能力（例如：妖精）。|
|PV|integer|基础防护值，即种族天生的防护能力（例如：魔像）。|
|PDR|integer|物理伤害减免，按百分比减少物理伤害。|
|EDR|integer|元素伤害减免，按百分比减少元素伤害。|
|EP|integer|完美闪避，额外的一层完美闪避保护，是一次独立的闪避判定。|
|STR/END/DEX/PER/LER/WIL/MAG/CHA/SPD|integer|基础属性参数。|
|ratio|—|用于估算种族强度的宏，游戏中未使用。留空即可。|
|INT|integer|种族的"智力"。INT 低于 `10` 的角色无法自行打开**上锁的门**；普通门没有智力要求。|
|martial|integer|格斗技能的初始等级。与九维属性一样属于种族自带的能力，在角色生成时应用。|
|pen|integer|游戏未使用。保留该列，值随意。|
|elements|elements|种族自带的固有效果，用于添加种族专长和基础技能加成（同时也会提高基础潜力）。格式：`元素别名/数值`。|
|skill|string|游戏未使用。本体这一列里写的是作者的备注（`●` 或空格分隔的技能名），不会被读取；真正生效的是 `elements` 列。|
|figure|string|种族初始拥有的身体部位。参见下方[部位参考](#部位参考)。|
|geneCap|integer|种族的基因槽数量。|
|material|string|种族的构成材质。|
|corpse|string[]|尸体掉落物，格式为 `物品ID,几率`。几率以 1500 为分母，默认 `_meat,20` 约合 1.3%。**两段都必须填**，缺少几率会在掉落时出错。|
|loot|string[]|种族专属的掉落物。|
|blood|integer|种族流血时留下的血迹贴花编号，与材质表的 `decal` 列共用一套编号。`2` 是普通的红色血液。可参考官方源表 `chara` 分表的 blood 列填写。同样遵循通用规则：留空则使用默认值。|
|meleeStyle|string|该种族**徒手攻击**时的攻击类型（拿着武器时用的是武器自身的类型，格斗类武器除外）。留空则每次在拳击与踢击之间随机。可选值：`Slash`、`Pierce`、`Blunt`、`Punch`、`Kick`、`Bow`、`Gun`、`Claw`、`Bite`、`Spore`、`Gaze`、`Sting`、`Touch`、`Cane`，**不区分大小写**。填写列表之外的词会在该角色徒手攻击时出错，而不是被忽略。|
|castStyle|string|种族的施法效果，主要用于风味文本。|
|EQ|string[]|只要非空，生成该种族的角色时就会启用装备生成；内容本身不会被读取，实际装备由角色表的 `equip` 列或职业的 `equip`/`weapon` 决定。本体使用 `"all"` 或空白。|
|sex|integer|游戏未使用（性别由角色表 `bio` 列的第一段决定）。保留该列，值随意。|
|age|integer[]|生成该种族角色时的年龄范围，格式为逗号分隔的 `起始,结束`。例如 `8,50` 表示生成时年龄在 8 到 50 之间。|
|height|integer|种族的平均身高。生成角色时在此基础上浮动约 20%。它还有两处容易忽略的影响：尸体的重量由身高决定；身高低于 500 且没有 `webfree` 标签的角色会被蛛网困住。|
|breeder|integer|作为牲畜饲养时的产崽几率，判定基准为 2500，数值越大越频繁（繁殖政策会降低基准，从而提高几率）。**填 `0` 并不等于不产出**：仍有约 1/2500 的概率，只是牧场界面会显示为 0%。|
|food|string[]|种族肉类品质的倍率（百分比）。只读取第一项。|
|fur|string|剪毛产出，格式为 `物品ID/材质别名`（例如 `fiber/wool`）。**只要这一列非空，该种族就可以被剪毛**，因此只填一半会在剪毛时出错。留空则不可剪毛。|
|detail_JP|string|种族的日文详情/背景故事。|
|detail|string|种族的英文详情/背景故事。|

## 标签参考

`tag` 列中常用的标签：

|标签|描述|
|-|-|
|`human`|可以使用通用语。|
|`fairy`|属于妖精。|
|`humanSpeak`|不是人形，但可以使用通用语。|
|`gelatin`|本体的胶状种族（如波球）带有这个 tag，但代码中未发现直接效果，胶状材质来自 `material` 列（`jelly`）。不建议使用 `gelatin` 标签。|
|`sand`|会在沙地地图生成。|
|`ride`|骑乘适应性良好。|
|`mofu`|会无差别地被所有人和事物骚扰、狂撸。|
|`fish`|视为鱼类，用于种族特攻判定。|
|`undead`|视为亡灵，用于种族特攻判定。无法被心灵感应侦测。|
|`god`|视为神。不要和神一起看鸟。|
|`animal`|视为动物，用于种族特攻判定；可出现在动物驯师处。|
|`sleepBeside`|属于你的阵营且在同一地图时，会试图睡在你身边。|
|`noRide`|骑乘适应性较差。|
|`insect`|本体的昆虫种族带有这个 tag，代码中未发现直接效果（仍可被 SpawnList 的 tag 过滤匹配）。|
|`plant`|视为植物。可被库米罗米支配。|
|`filth`|用途不明。|
|`dragon`|视为龙。|
|`webfree`|可自由穿越蛛网；用于蜘蛛。|
|`cat`|此种族是猫。不要吃。|
|`water`|会在水域地图生成。|
|`machine`|视为机械。可被玛尼支配，也可被玛尼霰弹枪的阵营效果升级。|
|`horror`|视为异形。无法被心灵感应侦测。|

## 部位参考

`figure` 列使用竖线（`|`）分隔的汉字来表示身体部位。同一个部位可以重复，写几次就有几个槽位，例如 `手|手|指|指` 表示两只手、两个手指槽。本体大多数人形种族是 `頭|首|体|背|手|手|指|指|腕|腰|脚|足|`。

|汉字|身体部位|
|-|-|
|`頭`|头部|
|`首`|颈部|
|`体`|躯体|
|`背`|背部|
|`手`|手部|
|`指`|手指|
|`腕`|手臂|
|`腰`|腰部|
|`脚`|腿部。**当前代码中已停用**，会被跳过，不产生槽位（本体行仍保留它）|
|`足`|脚部|
